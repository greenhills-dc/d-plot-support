Privacy Policy

D-PLoT (Dental Photo Layout Plotter)

Last updated: March 4, 2026

Introduction

The D-PLoT Development Team ("we", "us", or "our") respects your privacy and is committed to protecting your personal information. This Privacy Policy explains how our macOS application "D-PLoT" ("the App") handles information.

Information Collection

The App does not collect any personal information whatsoever.

Specifically, we do not collect, transmit, or store any of the following:

  • Personal identification information (name, email address, phone number, etc.)
  • Location data
  • Device identifiers
  • Usage data or analytics
  • Advertising identifiers
  • Patient information or medical data
  • Photos or image data

Data Processing

The App operates entirely offline.

  • Image Processing: All photos imported by the user are processed exclusively on the local device. No data is uploaded to external servers.
  • Project Files: Layout data (.dpcase files) is saved only to local folders specified by the user.
  • Exported Files: Generated image files are saved only to local folders specified by the user.
  • Settings: App settings (ingest order presets, export settings, etc.) are stored locally using macOS standard UserDefaults and Application Support directory.

Network Communication

The App does not require an internet connection. No network communication of any kind is performed.

Third-Party Sharing

The App does not provide, share, or sell data to third parties. No third-party SDKs, analytics tools, or advertising frameworks are used.

File System Access

The App accesses the file system for the following purposes:

  • Reading image files: Reading image files that the user has explicitly selected or dragged and dropped
  • Saving/reading project files: Saving and reading layout data to/from locations explicitly specified by the user
  • Saving exported files: Exporting image files to locations explicitly specified by the user

All file access is performed within the macOS App Sandbox, and access is limited to files and folders explicitly selected by the user.

Apple Privacy API Usage

The App uses the following Apple APIs:

  • File Timestamp API: Used to retrieve file modification dates for managing image ordering (reason code: C617.1)

Intended Users

The App is a professional tool designed for dental healthcare professionals. It is not intended for general consumers.

Medical Information Notice

The App is a dental photo layout creation tool and may handle medical information. However, the App does not include any functionality for transmitting, cloud-storing, or externally sharing medical information. Users are responsible for managing and protecting images containing patient information.

Changes to This Privacy Policy

This Privacy Policy may be updated without prior notice. When changes are made, the last updated date on this page will be revised.
